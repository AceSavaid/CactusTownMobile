# Credits

## Art

Some UI icons and mini-game art come from **Kenney** game assets
(<https://kenney.nl>), released under **Creative Commons Zero (CC0 1.0)** —
free for commercial use, crediting optional. Files live under `assets/kenney/`.

- Mobile Controls — icon set (`assets/kenney/icons/`)
- Puzzle Assets 1.1 — mini-game pieces (`assets/kenney/puzzle/`)
- UI Pack — green button / control set (`assets/kenney/ui-green/`)

All other art — the cactus, pots, town props, **town buildings**
(`assets/sprites/buildings/`), region nodes, store graphics — is original to
this project.

## Audio

Sound effects supplied by the developer. Music is procedurally synthesised
(`MusicBank` / `SfxBank`) pending real tracks.
